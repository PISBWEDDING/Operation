Phone

First time: add this page to your home screen

Kali pertama: tambah halaman ini ke skrin utama
  1. iPhone: open this page in Safari, tap Share ⬆ → Add to Home Screen → Add. Buka dalam Safari, tekan Kongsi ⬆ → Tambah ke Skrin Utama → Tambah.
  2. Android: open this page in Chrome, tap ⋮ → Add to Home screen → Add. Buka dalam Chrome, tekan ⋮ → Tambah ke skrin utama → Tambah.
  3. Next time, tap the PISB Operation icon on your home screen. Selepas ini, tekan ikon PISB Operation di skrin utama.
Computer

Install on a computer

Pasang di komputer
  1. Chrome: ⋮ → Cast, save and share → Create shortcut → tick Open as window → Create. ⋮ → Hantar, simpan dan kongsi → Cipta pintasan → Buka sebagai tetingkap → Cipta.
  2. Edge: ⋯ → Apps → Install this site as an app → Install. ⋯ → Aplikasi → Pasang laman ini sebagai aplikasi → Pasang.
  3. Mac Safari: File → Add to Dock → Add. Fail → Tambah ke Dock → Tambah.
